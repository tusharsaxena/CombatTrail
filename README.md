# Ka0s Combat Trail

Work in progress, not released. Your casts as a scrolling trail (Player and Pet lanes), a live DPS
HUD on every fight, and a history of your fights, on Retail and WoW Forever.

The design is in [`docs/superpowers/specs/`](docs/superpowers/specs/) and the build plan in
[`docs/superpowers/plans/`](docs/superpowers/plans/). The player-facing README arrives with the docs
task of the v0.1.0 plan.
