4. **After M4:** after-capture compared with the before-capture; any change with no measured gain is reverted.

## Commit strategy

One commit per task, or per milestone for M2. Messages follow the branch's existing style (`fix(review): …`, `fix(lanes): …`, `perf(hud): …`):
- `fix(casts): never cache a secret base cooldown (F-001)`
- `fix(watchers): a rejected event is never marked or unregistered (F-007)`
- `fix(review): route the last raw pet-exists tests and error strings through NS.Secrets (F-009, F-011)`
- `fix(tests): the combat-log invariant scans every authored file and cannot pass empty (F-008)`
- `perf(lanes): restyle an icon only when its lane's style changed (F-002)`
- `perf(casts): incremental live cast list; stable chart icon list (F-003)`
- `perf(hud): reuse live spell rows; one live read per tick (F-005, F-006)`
- `perf(fights): defer the bag and talent snapshots one frame at combat entry (F-004)`
- `docs: the live pace follows the pull target; the purge waits out combat (F-010, F-012)`
