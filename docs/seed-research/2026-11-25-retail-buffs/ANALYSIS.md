Hand-written. The rest of this bundle is generated by `tools/seeds/seeds.py`.

## Why this is its own bundle

CL-13a first derived the buff seeds into `docs/seed-research/2026-11-25-retail/`, the bundle the
same day's seeds run (SF-CT-01) had already frozen and merged. The spec named that directory. That
rewrote a frozen bundle, so the review fix pass (CL-REV) put the bundle back as it was merged and
derived the buff seeds here instead. The earlier bundle is the record of the hearthstone and ignore
run, and is never edited.

- **Same build.** `wow` 12.1.5.70961.
- **Where the tables came from.** `raw/` holds the merged bundle's six tables, unchanged, plus
  `Item`, which CL-13a fetched from wago.tools on 2026-11-25, pinned with `?build=`. This run
  replayed them (`derive --replay`), so `SOURCES.md` says so.
- **What else it repeats.** The hearthstone and ignore findings are repeated, because `derive`
  always writes every list, and they are ruled as before.

## Judgment calls applied

- **Unobtainable world buffs are accepted** (CL-13a). Listing an id that never appears costs
  nothing.
- **A proc is ruled by hand.** The DB2 cannot say what a proc aura (42) does. Dragonbreath Chili,
  a known raid food, is accepted. Every other proc is left for the owner.
- **Two earlier rejections are now backed by rule 2,** and they stay as they were ruled (precedent
  1). Really Well Fed 65247 is still a size aura. Regrettably Well Fed 383212 is still *needs owner
  review*, now with item 197772 as its source.

## The Retail list is Classic-era and event buffs only

Every one of the 25 Retail buffs is a legacy world, faire or festival buff. Several of them can no
longer be had on Retail, and no current-expansion fight buff is in `BUFF_CATALOG`. So the issue's
Retail acceptance ("A Retail fight with a seeded Retail buff lists it") can be met in game only
during Midsummer or the Lunar Festival, if at all. SM-CT-R35 is recorded as event-gated. **Owed:**
the owner names the current Retail fight buffs to track. They join through `BUFF_CATALOG`, then a
new run derives and rules them.
